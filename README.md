

# ElectroHub 🛒

ElectroHub is a modern electronics e-commerce website built with Next.js and TypeScript. It provides a clean shopping experience where users can explore electronic products, view product details, manage their cart, and proceed to checkout.

## ✨ Features

- 🏠 Attractive homepage
- 📱 Product listings and categories
- 🔍 Individual product detail pages
- 🛒 Add products to the shopping cart
- 🧺 View and remove cart items
- 💳 Checkout page
- 📞 Contact page
- 📱 Responsive layout
- ⚡ Fast navigation with Next.js

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- JavaScript
- HTML

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/selahudin888/electrohub.git
```

### 2. Open the project

```bash
cd electrohub
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open in your browser

Visit:

http://localhost:3000
